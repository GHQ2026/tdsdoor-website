## 一、两条路，你挑一条

| | 方式 A：可视化后台 | 方式 B：GitHub 网页直接改 |

## 二、方式 A：可视化后台（推荐）

### 第 1 步：生成一次"钥匙"（这辈子只做这一次）

这把"钥匙"叫 **PAT（个人访问令牌）**，作用是让后台有权限把你的修改写回仓库。

1. 打开 👉 **https://github.com/settings/tokens?type=beta**
   （需要登录你的 GitHub 账号 GHQ2026）
2. 点 **Generate new token**
3. 按下面填写：

   | 项目 | 填什么 |
   |------|--------|
   | Token name | `拓达昇官网后台` |
   | Expiration（有效期） | 建议选 **Custom** → 一年后（到期前重新生成一次即可） |
   | Repository access | 选 **Only select repositories** → 勾选 `tdsdoor-website` |
   | Permissions → Repository | 找到 **Contents**，改成 **Read and write**（其余不用动） |

4. 拉到最下面点 **Generate token**
5. **立刻复制那串字符**（以 `github_pat_` 开头），关掉页面后就再也看不到了
   👉 建议先粘贴到记事本存着

### 第 2 步：登录后台

1. 浏览器打开 **`你的网址/admin/`**
   目前临时地址：`https://171afb18c2b54f81813cc4e823f00f57.app.workbuddy.link/admin/`
2. 点 **Sign in with access token**（用令牌登录）
3. 粘贴刚才那串 `github_pat_...`，确认

> 浏览器会记住这把钥匙，**以后直接打开 /admin/ 就能改**，不用再登录。

### 第 3 步：日常改内容

登录后你会看到左侧菜单：

| 菜单 | 能改什么 |
|------|---------|
| 站点内容 → 全站内容 | 公司名称、电话、地址、首页主标题副标题 |
| 站点内容 → 新闻动态 | 新闻的日期 / 标题 / 摘要，**可加可删** |
| 站点内容 → 案例与方案 | 案例标题 / 所属行业 / 描述，**可加可删** |
| 站点内容 → 核心工业门产品 | 6 大主打产品的名称、卖点、参数、应用行业、封面图 |
| 站点内容 → 产品体系全景 | 6 大分类下所有子类目的名称与图片 |
| 站点内容 → 关于我们页 | 企业简介段落 |

改完点右上角 **Save（保存）** → 弹窗再点 **Publish（发布）**。

### 第 4 步：等它自动上线

保存后约 **1～3 分钟**，网站自动重新生成并上线。**你什么都不用再做。**

想确认有没有成功：打开 https://github.com/GHQ2026/tdsdoor-website/actions
看到绿色的 ✅ 就是成功了，红色 ❌ 就是有问题（把截图发给技术同事）。

## 三、方式 B：GitHub 网页直接改（零配置，备用）

适合临时改几个字，不用任何准备。

1. 打开 👉 **https://github.com/GHQ2026/tdsdoor-website/blob/main/content/content.json**
2. 点右上角的 **铅笔图标**（Edit this file）
3. 找到要改的文字，直接改
4. 拉到页面最下面：
   - **Commit changes** 按钮上方有个输入框，随便填一句说明，比如"更新新闻"
   - 保持选中 **Commit directly to the main branch**
   - 点 **Commit changes**
5. 等 1～3 分钟，网站自动更新

### 改的时候注意这几点（很重要）

- **只改引号里面的文字**，不要动引号、逗号、花括号 `{}`、方括号 `[]`
- 中文标点随意用，但**引号必须用英文双引号 `"`** 包住文字
- 如果改完保存时提示格式错误，点 **Cancel** 放弃重来，别硬保存

### 各段文字对照表

| 想改哪里 | 找这个字段 |
|---------|-----------|
| 公司名称 / 电话 / 地址 / 首页标题 | `site` |
| 首页数字（如"服务客户 500+"） | `stats` |
| 6 大主打工业门 | `products` |
| 产品体系全景 6 大类 | `categories` |
| 客户 LOGO 墙 | `clients` |
| **案例与方案** | `cases` |
| **新闻动态** | `news` |
| 关于我们 | `about` |

**新闻（news）一条长这样**，照着改就行：

```json
{
  "date": "2026-08-20",
  "title": "合肥经开区某物流园快速门项目完成交付验收",
  "summary": "近日，公司承接的合肥经开区某物流园区快速门项目顺利完成交付验收……"
}
```

要加一条新闻：复制上面这整段（包括花括号），粘贴到上一条后面，**记得在两段之间加一个英文逗号 `,`**。

**案例（cases）一条长这样**：

```json
{
  "title": "合肥经开区某新能源产业园洁净车间快速门项目",
  "industry": "新能源 / 锂电",
  "desc": "为合肥经开区某新能源电池生产车间提供 PVC 快速卷帘门 12 樘……"
}
```

## 四、换图片

### 用后台（方式 A）
在产品/分类编辑界面找到图片字段，点 **Upload** 上传即可。
图片会自动存到 `site/assets/images/`，发布后就能看到。

### 用 GitHub（方式 B）
1. 打开 https://github.com/GHQ2026/tdsdoor-website/tree/main/site/assets/images
2. 点 **Add file → Upload files**，把图片拖进去
3. 提交后，在 `content.json` 里把图片名改成新名字（如 `"image": "新图片.jpg"`）

> **图片建议**：产品图统一 **1600×900 像素**、JPG 格式、单张不超过 500KB。
> 图太大网站打开会慢，这点对客户体验影响很大。

## 五、常见问题

**Q：改完多久能看到？**
A：1～3 分钟。如果超过 5 分钟没变，去 Actions 页面看是不是红色 ❌。

**Q：改坏了怎么办？能撤销吗？**
A：能。GitHub 保存了每一次修改记录。打开
https://github.com/GHQ2026/tdsdoor-website/commits/main
找到出事前那一次，点进去可以还原。**改坏了不用慌，不会丢。**

**Q：提示保存失败 / 没权限？**
A：多半是"钥匙"过期了（默认一年）。重新做一遍"第 1 步"生成新钥匙，重新登录即可。

**Q：我能让别人也改吗？**
A：可以，但需要在 GitHub 仓库 Settings → Collaborators 里邀请对方，
对方也要自己生成一把钥匙。**注意：拿到钥匙的人就能改网站内容，钥匙不要外传。**

**Q：手机能改吗？**
A：能。手机浏览器打开 `你的网址/admin/` 即可，界面会自动适配。

## 六、重要提醒

1. **钥匙（PAT）不要发给别人**，等同于网站编辑权限
2. 新闻和案例**内容要真实、不夸大**，写具体数字（多少樘门、多少天完工），
   比写"大幅提升""行业领先"更能让客户信任，搜索引擎也更喜欢
3. 建议**每月发 2～4 条真实新闻或案例**，活跃更新的网站排名会越来越好
4. 改完记得去网站上看一眼，确认显示正常
