# 拓达昇 TODOSUN 官网 — UI/UX 设计方向文档

> 生成日期：2026-08-28 | 设计师：颜好看（UI/UX 设计专家）
> 阶段：Phase 1 设计方向（非高保真稿） | 用途：Phase 2 高保真设计与 Phase 3 前端实现的设计契约源
> 依据：用户需求（浅色、简约、专业、高级，对标华为/苹果/特斯拉式大厂气质）+ 既有视觉资产（logo 蓝橙三角、7 张工业门产品图、威得力式参考变体）

## 0. 设计定盘星

### 0.1 寄存器判断

本项目是**双寄存器**项目，两套策略严格分开：

| 部分 | 寄存器 | 设计标杆 |
|---|---|---|
| 官网前台（首页/关于/产品/案例/新闻/联系） | **Brand 寄存器** — 设计即产品，承担"让采购方第一眼信任"的转化使命 | DJI / 华为 / Festo / GE Vernova |
| CMS 后台 | **Product 寄存器** — 设计服务内容编辑这一产品功能，标杆是"赢得熟悉感" | Notion 后台 / Linear 设置页 |

### 0.2 三轴设计刻度

| 刻度 | 官网前台 | CMS 后台 | 理由 |
|---|---|---|---|
| DESIGN_VARIANCE | **4**（可预测偏对称） | 3 | 工业制造的气质是"秩序、精密、对称"，非对称艺术化会损害信任感；参考图选定"威得力式居中对称变体"印证此判断 |
| MOTION_INTENSITY | **3**（克制） | 2 | 浅色高级感的来源是"稳"，动效只做 hover 反馈与内容进入，不做滚动劫持/视差轰炸 |
| VISUAL_DENSITY | **4**（宽松） | 6（紧凑） | 官网需要大留白撑气质；CMS 需要信息密度撑效率，但保持表单优先、无驾驶舱式数据墙 |

### 0.3 一句话设计方向

> **"精密制造工厂的产品目录册"**：像 DJI 用浅灰画布衬托无人机一样，用浅灰摄影风画布衬托工业门产品本身——产品图是主角，界面退到最后面，蓝色负责秩序，橙色只在关键处点一笔。

## 1. 对标品牌与理由（联网调研结论）

### 1.1 主对标：DJI 大疆（dji.com）

**为什么**：DJI 是"硬件制造 + 浅色画布 + 产品摄影主导"范式的全球最佳实践，与本项目资产（浅灰摄影风产品图）天然匹配。

调研提炼的可复用范式（来源：styles.refero.design 对 dji.com 的设计系统解构）：
- **画布策略**：页面画布用略冷灰 `#ededed`（低于纯白），卡片表面用纯白 `#ffffff`——产品摄影在灰画布上比在白底上更"跳"
- **几乎无阴影的表面系统**：产品卡平铺、无装饰性边框，全部视觉重量由产品摄影承担
- **单一品牌色做所有工作**：一个信号蓝承担品牌识别、激活态、常驻 CTA；排版近乎单色
- **技术感排版**：大字号用小字重（300-500）+ 收紧字距（-0.02em ~ -0.03em），营造"工程仪器感"而非"广告感"
- **幽灵链接 + 箭头**：列表项链接用文字 + chevron，不用按钮堆砌

### 1.2 副对标一：华为（huawei.com）

**为什么**：用户明确点名"华为式大厂气质"。华为官网的底色是克制的信息层级 + 稳定的栅格。

调研提炼（来源：华为开发者联盟 UX 规范）：
- **栅格纪律**：margin=24、gutter=24 的基础栅格；同一应用内不同页面边距不发生明显变化——"稳定"是专业感的底层来源
- **留白上限**：大屏页面留白率不超过 70%——克制留白但不空洞
- **中文阅读行宽**：中文单行舒适字数约 32 字、上限约 42 字（正文栏宽据此推导为 620-680px）
- **产品位排版**：上文下图结构、图片高度占屏 40-50%，居中对齐

### 1.3 副对标二：Festo + GE Vernova（制造业 B2B 专项）

**为什么**：本项目是 B2B 为主的工业门制造企业，需要制造业官网的信任构建范式（来源：beetlebeetle/axongarside 2025 制造业官网最佳设计分析）。

- **Festo 式"精密克制"**：超净白/单色版面 + 精密线性图标 + 技术网格间距 + 微交互（hover 高亮）——"我们不需要噪音，产品细节自己会说话"
- **GE Vernova 式"企业级信任"**：大字排版 + 慷慨留白 + premium restraint（高级的克制）+ 全球布局图 + 资质证书带
- **制造业官网共性结论**（四篇调研一致）：真实项目照片 >> 通用图库；技术参数前置且可检索；认证/案例是必备信任模块；CTA（询盘/获取方案）必须明确且常驻

### 1.4 反面清单（明确不学）

- [DON'T] Caterpillar 式深色重工业 grit 风（与"浅色简约高级"定位冲突）
- [DON'T] Northvolt 式玻璃拟态 + 大面积渐变（AI 模板味高危区）
- [DON'T] 紫粉渐变、emoji 图标、抽象 3D 图形 Hero（P0 红线）

## 2. 设计语言定义

### 2.1 四条设计原则（全项目纪律）

1. **产品即主角**：任何版面里，产品摄影 > 文字 > 图形装饰。界面元素存在感从后往前排。
2. **秩序即高级**：对齐、栅格、间距的绝对纪律比任何视觉花活更能传达"大厂感"。居中对称是官网的默认姿态（承接威得力式参考）。
3. **蓝建秩序，橙点睛**：品牌蓝负责结构（导航激活、标题装饰线、CTA、数据条）；橙色每屏最多 1-2 处，只出现在"最想让用户看见的那一个点"。
4. **克制的物理感**：阴影只用于悬浮/弹出层；静态卡片用 1px 边框 + 白色表面分层，不用投影堆层级。

### 2.2 版式栅格

| 项 | 规格 |
|---|---|
| 栅格 | 桌面 12 列 / 平板 8 列 / 手机 4 列 |
| 容器最大宽度 | `--container-max: 1200px`（官网主内容）；产品详情正文栏 680px（中文阅读舒适行宽） |
| 沟槽 gutter | 桌面 24px / 平板 16px / 手机 12px（对齐华为栅格纪律） |
| 页面左右边距 | 桌面 ≥32px，且全站所有页面一致（不随页面漂移） |
| 节区纵向节奏 | 桌面 80px / 平板 48px / 手机 32px（`--section-y-*`） |
| Hero 高度 | 桌面 60-72vh，内容底部偏移不垂直居中 |
| 留白率 | 40-60%（页面留白不超过 70%，不空洞） |
| 对齐策略 | 官网模块内标题-内容居中对称（威得力式）；正文段落左对齐；数据带居中对称 |

### 2.3 间距体系（4px 网格）

仅允许：`4 8 12 16 20 24 32 40 48 64 80 120`
Token：`--space-1`(4px) 至 `--space-30`(120px，仅 Hero 纵深)。

关键间距语义：
- 卡片内边距：24px（`--space-6`）
- 模块内元素间距：16-24px
- 数据带项目间距：48px（桌面）/ 24px（移动）
- 表单字段间距：24px；label 与输入框间距：8px

### 2.4 字体系统

```css
--font-display: "Inter", "Noto Sans SC", -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
--font-body:    "Inter", "Noto Sans SC", -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
--font-mono:    "JetBrains Mono", "SFMono-Regular", Consolas, monospace; /* 型号/参数表/尺寸数据 */
```

- 中文主导 + 英文品牌名 TODOSUN 并存：英文数字走 Inter（技术感），中文回退 Noto Sans SC（思源黑体），保证中英混排基线一致
- Google Fonts `@import`：`Inter:wght@400;500;600` + `Noto+Sans+SC:wght@400;500;700`；国内部署需准备字体子集化或 CDN 镜像（交接架构师确认）
- 数字一律 `font-variant-numeric: tabular-nums`（数据带、参数表对齐的关键）

**字号层级（9 级）与用途：**

| 级别 | Token | px | 用途 | 字重 | 行高 | 字距 |
|---|---|---|---|---|---|---|
| 展示字 | `--text-5xl` | 48 | Hero 主标题 | 500 | 1.1 | -0.02em |
| 大标题 | `--text-4xl` | 40 | 首屏副级大标题 | 500 | 1.15 | -0.02em |
| H1 | `--text-3xl` | 32 | 页面主标题 | 600 | 1.2 | -0.01em |
| H2 | `--text-2xl` | 24 | 节区标题 | 600 | 1.3 | -0.01em |
| H3 | `--text-xl` | 20 | 卡片/模块标题 | 500 | 1.4 | 0 |
| H4 | `--text-lg` | 18 | 小节标题 | 500 | 1.5 | 0 |
| 正文 | `--text-base` | 16 | 正文（官网默认基准） | 400 | 1.7 | 0 |
| 辅文 | `--text-sm` | 14 | 辅助说明、CMS 列表 | 400 | 1.6 | 0.01em |
| 微文 | `--text-xs` | 12 | 标签、面包屑、版权 | 400 | 1.5 | 0.02em |

- **ALL CAPS 英文标签**（如 "TODOSUN INDUSTRIAL DOORS"）：letter-spacing ≥ 0.08em，仅用于页脚品牌行与产品型号徽标，正文区禁用
- 大标题用 500 而非 700 —— DJI 式"轻字重大字号"工程感，中文黑体 600 为上限，避免"广告横幅感"

## 3. 色彩 Token 体系

### 3.1 色彩策略总述

四层配比：**中性色 85% / 品牌蓝 10% / 强调橙 ≤3% / 语义色 <2%**。
画布双层策略（DJI 范式）：页面画布浅灰 `#F7F7F7`，卡片/导航表面纯白 `#FFFFFF`——产品摄影在灰底上更突出，白卡片自带 1 层"浮起"而无须阴影。
所有颜色含轻微蓝灰倾向（不用纯灰 `#808080`），呼应"工业精密"气质。

### 3.2 中性色阶（Neutral — 表面与文本）

| Token | 值 | 用途 | 对比度（vs #F7F7F7 画布） |
|---|---|---|---|
| `--neutral-0` | `#FFFFFF` | 卡片表面、导航条、输入框 | — |
| `--neutral-50` | `#FAFAFA` | 表格斑马纹、次级画布 | — |
| `--neutral-100` | `#F7F7F7` | **页面画布（A1: --bg）** | — |
| `--neutral-200` | `#EDEEF0` | 节区底色交替、分割带 | — |
| `--neutral-300` | `#E1E4E8` | 边框（A1: --border）、输入框描边 | — |
| `--neutral-400` | `#C6CBD2` | 禁用态边框、滑轨 | 1.9:1（仅装饰元素） |
| `--neutral-500` | `#98A1AB` | 占位符、禁用文本 | 2.9:1（禁用豁免） |
| `--neutral-600` | `#5F6B7A` | 副文本（A1: --muted）、说明文字 | **5.0:1 √ AA** |
| `--neutral-700` | `#3A4552` | 次级标题、表头 | 8.6:1 √ AAA |
| `--neutral-800` | `#242E3B` | 正文（B-slot: --fg-2） | 12.5:1 √ AAA |
| `--neutral-900` | `#14202E` | 主文本/标题墨色（A1: --fg），带蓝调的深墨 | **15.2:1 √ AAA** |

### 3.3 品牌蓝色阶（Structure Blue — 主色）

基准 `--blue-600: #0B4F8C`（用户锁定品牌蓝，来自 logo 三角）。

| Token | 值 | 用途 |
|---|---|---|
| `--blue-50` | `#EEF4FA` | 选中态背景、信息条底色 |
| `--blue-100` | `#D9E7F3` | hover 背景、focus ring 外圈 |
| `--blue-200` | `#B4D0E7` | 进度条轨道、图表次系列 |
| `--blue-300` | `#82B0D3` | 禁用态主色、图表辅助 |
| `--blue-400` | `#4F8BB8` | 图表系列、装饰性线条 |
| `--blue-500` | `#2A6DA3` | 文本链接色（5.2:1 √ AA） |
| `--blue-600` | `#0B4F8C` | **主色（A1: --accent 语义下的 primary）**：导航激活、CTA、数据条、标题装饰线 |
| `--blue-700` | `#0A4274` | 主色 hover（A2: --primary-hover） |
| `--blue-800` | `#09375F` | 主色 active |
| `--blue-900` | `#082C4A` | 页脚深色带背景 |

**关键对比度结论：**
- `#0B4F8C` 文本/图标 on `#F7F7F7` 画布 = **7.8:1 √ AA/AAA**（标题装饰、数据条数字可直接用）
- `#FFFFFF` 文本 on `#0B4F8C` 按钮 = **8.4:1 √ AAA**（主 CTA 安全）
- `#0B4F8C` on `#FFFFFF` 白卡 = **8.6:1 √ AAA**

### 3.4 强调橙（Accent Orange — 点睛色）

基准 `--orange-400: #E8922A`（用户锁定，来自 logo 渐变三角）。

| Token | 值 | 用途 |
|---|---|---|
| `--orange-50` | `#FDF3E7` | 高亮底色（极克制使用） |
| `--orange-100` | `#FAE3C8` | 悬停底色 |
| `--orange-200` | `#F4C88E` | 装饰渐变浅端（仅 logo 同源场景） |
| `--orange-300` | `#EFB05C` | 图表系列 |
| `--orange-400` | `#E8922A` | **点睛色**：数据条高亮项、关键徽标、悬停箭头 |
| `--orange-600` | `#B36A10` | 深橙（图形用深态） |
| `--orange-700` | `#A85E0D` | **橙色文本专用**（4.6:1 √ AA on #F7F7F7） |

**橙色使用纪律（硬规则）：**
1. `#E8922A` **禁止用于正文文本**（on 白/灰底仅 2.4:1，不达标）；需要橙色文字时一律用 `--orange-700 #A85E0D`
2. `#E8922A` 上的文字必须用 `--neutral-900` 深墨色（6.7:1 √），不用白字（2.5:1 ×）
3. 每屏可见橙色 ≤2 处：推荐位置 = 数据带中"最关键的一项数据"、产品卡 hover 时的箭头/描边
4. 橙色不做大面积背景、不做渐变横幅（logo 渐变三角是唯一允许的橙蓝渐变载体）

### 3.5 语义色（A2）

| Token | 值 | 用途 | 对比度说明 |
|---|---|---|---|
| `--success` | `#1E7F4F` | 成功提示、在线状态 | 4.9:1 √ AA |
| `--warn` | `#B45309` | 警告（琥珀，刻意与品牌橙拉开明度） | 4.8:1 √ AA |
| `--danger` | `#C13333` | 错误、删除 | 5.3:1 √ AA |
| `--info` | `--blue-600` | 信息提示（复用主色，减少色相数量） | 7.8:1 √ |

### 3.6 语义 Token 映射表（四层架构落地）

```
A1-identity:  --bg(#F7F7F7) --surface(#FFFFFF) --fg(#14202E) --muted(#5F6B7A)
              --accent(#0B4F8C 蓝主) --border(#E1E4E8) --font-display --font-body
A2-structure: --space-* --radius-* --text-* --primary-hover(#0A4274) --success/--warn/--danger
B-slot:       --fg-2(#242E3B) --surface-warm(#EDEEF0) --meta(#98A1AB) --border-soft(#EDEEF0)
              --focus-ring(0 0 0 3px rgba(11,79,140,.35))
C-extension:  --accent-orange(#E8922A) --accent-orange-text(#A85E0D) --footer-bg(#082C4A)
              --stat-bar(品牌蓝数据条) --canvas-alt(#FAFAFA)
```

每屏强调色执行口径：**蓝算主色（CTA+导航激活+数据条为常规配置）；橙为真正受限的 accent，每屏 ≤2 处。**

## 4. 图标系统

- **锁定库：Lucide**（统一 2px 描边、24×24 viewBox、MIT 开源、SVG 直出，与"精密线性图标"的 Festo 范式完全一致）。全项目一套、不混用，需与架构师在 Spec 中确认打包方式（推荐 `lucide-static` SVG sprite 或按需引入）。
- 尺寸三档：**16px**（行内/breadcrumb）/ **20px**（按钮内、表单）/ **24px**（独立功能图标、CMS 侧边导航）
- 描边：`stroke-width: 2`（16px 缩放档用 2.5 保持视觉重量）；颜色仅允许 `currentColor`
- 常用语义映射：产品分类=layout-grid / 询盘=message-circle / 下载=file-down / 电话=phone / 参数=table-2 / 案例缩略=building-2 / 安全认证=shield-check / 箭头=chevron-right(箭头一律随文字基线、尺寸 16-20px)
- **绝对零 emoji**（P0）：包括 CMS 后台的提示文案中也不用 emoji 代替图标
- Logo 使用规范：导航条高度内 logo 高度 32px；深色页脚用白色版 logo；logo 周围留白 ≥ logo 高度的 1/2

## 5. 图片处理规范

既有资产：7 张 1536×1024（3:2）浅灰摄影风产品图 + 蓝橙三角 logo。

### 5.1 比例与裁切

| 场景 | 比例 | 裁切规则 |
|---|---|---|
| Hero 主视觉 | 21:9（桌面）/ 4:3（移动） | 门体完整入画，产品居中或右置，左侧留文字呼吸区 |
| 产品卡封面 | **3:2**（与素材原生一致，零裁切损耗） | 门体完整、底部留浅灰地面；统一 `object-fit: cover; object-position: center` |
| 案例封面 | 16:9 | 允许环境裁切，保留门体与人参照物比例感 |
| 新闻封面 | 3:2 | 同产品卡 |
| CMS 缩略图 | 1:1 | 中心裁切 |

### 5.2 表现处理（克制原则）

1. **圆角**：图片统一 `--radius-md: 8px`；Hero 大图 `--radius-lg: 12px`。禁止 ≥24px 的大圆角（廉价化风险）
2. **阴影**：静态图片**零阴影**，靠灰画布与白卡片的明度差分层（DJI 无阴影表面系统）；仅悬浮弹层用 `--shadow-md`
3. **边框**：白底卡片内的图片不加边框；灰画布上的裸图（Hero/全宽图）加 `1px solid var(--border)` 收边
4. **禁用滤镜花样**：不加灰度 hover 变彩色、不加缩放 >1.03 的 hover zoom、不加暗色遮罩渐变（图文卡除外，遮罩为纯色 `rgba(8,44,74,.55)` 单色遮罩，不用蓝紫渐变）
5. **hover 反馈**（产品卡）：图片不动，卡片边框 `--border → --blue-600` 过渡 150ms + 标题变蓝 + 箭头平移 4px。"产品不动、界面动"是硬件官网的成熟范式
6. **格式与性能**：全站 WebP/AVIF + 原图 PNG 兜底；懒加载；提供 480/768/1200/1536 四档 srcset；CLS < 0.1（所有图片容器用 aspect-ratio 预留占位）
7. **图片气质统一**：新增素材必须延续"浅灰影棚底 + 侧逆光 + 冷色调"的既有摄影语言；禁止混入暖调车间实拍/纯白底图

## 6. 页面版式框架

### 6.1 全局框架

- **顶部导航**：高 72px，白底 `--surface` + 底部 1px `--border`，滚动后保持白底不透明（不做毛玻璃）。左 logo、中导航（首页/产品中心/案例/新闻/关于/联系，6 项）、右"获取方案"主 CTA（蓝底白字）+ 电话。移动端 ≤768px 折叠为汉堡菜单 + 底部无 TabBar（官网非应用，用抽屉导航）
- **页脚**：深蓝 `--blue-900` 底 + 白/浅灰文字 + 白色版 logo。含产品分类导航、联系方式、备案号。全站唯一的深色大区块，形成"浅-浅-浅-深"的首尾呼应结构
- **通用节区标题范式**（威得力式居中对称）：居中 H2 + 下方一行居中副文（--muted）+ 标题上方 32px 宽 3px 高品牌蓝短横线（`--stat-bar` 装饰线，全站唯一标题装饰，替代"小型大写追踪标签"这种 AI 语法）

### 6.2 首页（转化主场）

版块顺序（自上而下）：

1. **Hero**（灰画布）：左文右图非对称——左侧 H1（48px/500/-0.02em）+ 一句价值副文 + 主 CTA"获取门体方案"（蓝）+ 次 CTA"查看产品"（幽灵按钮）；右侧 hero-products.png。**禁止**"大标题+居中CTA+抽象图形"模板。H1 建议方向："工业门系统，为连续生产而设计"式——具体业务语句，不喊口号
2. **数据带**（威得力式核心承袭，白底全宽）：4 项居中对称数据（如：产品型号数量 / 服务客户行业数 / 交付项目 / 响应时效——以用户提供真实数字为准，禁虚构"9999+"式数字）。样式 = 大数字（32-40px，tabular-nums，蓝）+ 小标签（14px，muted），项间 48px，顶格 1px 分割线；其中**最关键一项数字用橙色**（全页唯一橙）
3. **产品分类入口**（灰画布）：4 分类卡片，白底 1px 边框，3:2 图 + 分类名 + "查看"幽灵链接
4. **主打产品精选**：6 款主打工业门，2 行 ×3 列网格（移动 1 列）。卡片 = 3:2 图 + 型号名 + 一行参数摘要（mono 字体）+ hover 边框变蓝
5. **为什么选择我们**：左图右文分栏（华为式），3 条实力点用 Lucide 线性图标 24px + 标题 + 说明
6. **精选案例**：2-3 个案例横排卡，16:9 图 + 客户行业标签 + 一句话成果
7. **资质与信任带**：白底窄条，认证图标/名称横排（Festo/GE 式 trust bar）
8. **CTA 收尾**（蓝底 `--blue-600` 全宽窄条）：一句话 + 白色按钮"联系工程师获取报价"

### 6.3 列表页（产品中心 / 案例 / 新闻通用范式）

- 顶部页头：面包屑（12px muted）+ H1（32px）居中 + 副文，下方 1px 分割线
- 产品中心：左侧分类筛选（桌面）/ 顶部横向滚动 chips（移动），右侧 3 列产品卡网格；筛选状态用蓝 `--blue-50` 底 + 蓝描边 chip
- 案例/新闻：3 列或 2 列卡片流 + 分页（数字分页器，非无限滚动——B 端用户需要可预期的浏览）
- 空状态：居中图标 24px + "暂无相关内容" + 引导文案（如"试试其他分类"），禁用空白区域

### 6.4 产品详情页（核心转化页）

结构（左右分栏起步，向下全宽展开）：

1. **首屏**：左侧 40% 信息区（型号名 H1 + 分类徽标 + 三行核心参数 mono 表 + 询价 CTA + 电话）；右侧 60% 主图 3:2 + 缩略图列
2. **详细参数表**：全宽白卡，两列 dl 表（左灰底表头栏），数字全部 tabular-nums mono；可下载规格书（file-down 图标 + 幽灵按钮）
3. **应用场景**：2×2 图文格
4. **相关产品**：3 卡横排
5. **询盘 CTA 尾部**：同首页收尾条

### 6.5 关于页

- 公司叙事区（左文右图）、时间线（年份 mono + 事件，竖线用 `--border`）、厂区/团队图墙（3:2 统一）、价值观三栏（图标克制，不彩色底）
- 禁止"我们的使命是成为世界一流企业"式空话，用事实句（成立年份、产能、覆盖行业）

### 6.6 新闻列表/详情

- 列表：日期（mono，muted）+ 标题 + 摘要卡
- 详情：680px 正文栏，16px/1.7；标题区含日期与分类徽标

### 6.7 联系页（表单页范式）

- 左右分栏：左侧公司信息（地址/电话/邮箱，Lucide 16px 行内图标）+ 地图占位；右侧表单卡（白底 1px 边框 8px 圆角）
- 表单纪律：每个字段**可见 label**（禁 placeholder 当 label）；姓名/电话/需求类型/留言 4 字段封顶（认知负荷 ≤4）；电话 `type="tel"`；提交按钮含 loading 态（spinner + "提交中…"）；成功后行内成功条 + 保留已填内容防刷新丢失；错误就近字段红框 + 具体错误文案（"请输入 11 位手机号"而非"格式错误"）

## 7. CMS 后台易用性设计原则（Product 寄存器）

受众是非技术用户（市场/行政人员），设计目标：**第一次进后台也能凭直觉完成"改一张产品图"**。

### 7.1 信息架构与布局

- 经典三段式：左侧固定导航（240px，白底，图标 20px + 文字，激活项蓝 `--blue-50` 底 + 蓝左标识）+ 顶部条（面包屑 + 当前用户）+ 内容区（灰 `--neutral-50` 画布，白卡承载表单/表格）
- 菜单仅 6 组，用业务语言不用技术语言："产品管理 / 案例管理 / 新闻动态 / 询盘留言 / 图片素材 / 账号设置"——不出现"节点/实体/模型"等词

### 7.2 十条易用性硬规则

1. **表单即编辑**：列表页点"编辑"进入全页表单（非弹窗编辑复杂内容），顶部固定"保存/取消"，离开未保存时拦截提示
2. **所见即所得预览**：编辑页右侧实时预览官网效果（桌面/手机切换图标），编辑者永远看得到用户将看到什么
3. **图片上传零术语**：上传组件 = 大虚线拖拽区 + "选择图片"按钮；自动压缩/裁切到规范比例，非专业参数（尺寸/格式报错转译成人话："图片太大，请选择小于 5MB 的图片"）
4. **草稿自动保存**：每 30s + 失焦自动存草稿，顶部显示"已自动保存 于 14:32"，杜绝"写半小时关窗口全没"
5. **危险操作双确认**：删除需模态确认 + 输入标题前缀或勾选确认（删除产品会同时影响官网展示，文案说明后果）
6. **操作可撤销**：删除进回收站（30 天可恢复），而非物理删除
7. **状态徽标化**：草稿(灰)/已发布(绿)/已隐藏(琥珀) 三态徽标，列表一眼可辨
8. **空状态即教程**：每个列表空状态配"新建第一个产品"引导按钮 + 一句话说明，把 onboarding 融入空状态
9. **反馈即时**：所有保存/删除操作 200ms 内给结果（成功 toast 顶部居中 3s 自动消失；失败 toast 常驻 + 重试按钮）
10. **移动可用**：后台支持 ≥768px 平板操作（列表变卡片、侧导航可收起）——很多工厂管理者用手机查询盘

### 7.3 视觉规范差异（vs 官网）

- 字号整体降一档（正文 14px），密度提至 6：表格行高 48px、表单字段间距 16px
- 色彩进一步收敛：CMS 内橙色**完全不出现**（避免与"警告"混淆），仅蓝 + 语义色
- 表格范式：表头灰底 `--neutral-100` + 600 字重；行 hover `--blue-50`；操作列固定右侧，按钮为 20px 图标 + 文字（不裸图标，非技术用户需要文字标签）

## 8. 动效规范

| 场景 | 时长 | 缓动 |
|---|---|---|
| hover（边框/颜色/箭头平移） | 150ms | ease-out |
| 下拉/抽屉/Toast 进入 | 200ms | ease-out |
| 模态框 | 250ms | ease-in-out |
| 内容滚动进入（官网节区淡入上移 12px） | 300ms，仅一次 | ease-out |
| 页面路由切换 | 200ms 交叉淡入 | linear |

- 禁止：弹跳缓动、视差滚动、滚动劫持、循环装饰动画（脉冲/漂浮）、>400ms 动画
- 全站支持 `prefers-reduced-motion: reduce`（动画全部退化为瞬时切换）
- 同屏同时动画元素 ≤3

## 9. 无障碍与响应式

- **对比度**：正文/功能文本全部 ≥4.5:1（见 §3 各表实测值）；非文本 UI（图标/边框交互态）≥3:1
- **键盘**：全站可 Tab 导航，`:focus-visible` 用 `--focus-ring: 0 0 0 3px rgba(11,79,140,.35)` 蓝环，焦点环不被 overflow 裁切
- **触摸目标**：移动端所有可点元素 ≥44×44px，CTA 按钮高 48px（桌面 44px）
- **表单**：label 显式绑定（`<label for>`），错误用 `aria-describedby`，禁用占位符当标签
- **图片 alt**：产品图 alt = 具体型号与门类（"拓达昇 PVC 快速卷帘门 TDS-PVC300"），装饰图 `alt=""`
- **断点**：sm 640 / md 768 / lg 1024 / xl 1280；<768px 单列回退、导航抽屉化、数据带 2×2、参数表转置为上下结构
- **5 态覆盖**：官网表单（Loading/Empty/Error/Populated/Edge 超长文本折叠）；CMS 列表（Loading 骨架屏/Empty/Error 重试/Populated/Edge 分页上限）

## 10. Do's & Don'ts

### [DO] 应该做

1. 产品摄影永远占据视觉重量第一位，界面退后
2. 灰画布 + 白卡片 + 1px 边框分层，静态零阴影
3. 居中对称的节区节奏 + 绝对稳定的栅格边距
4. 中文正文 16px/1.7，参数与数字用 mono + tabular-nums
5. 每屏橙 ≤2 处，橙色文字只用 `#A85E0D`
6. CTA 语义具体（"获取门体方案"而非"立即咨询"式空泛）
7. 真实数据、真实案例照片、可下载规格书
8. CMS 用业务语言 + 所见即所得 + 自动草稿

### [DON'T] 禁止做

1. 紫粉渐变、玻璃拟态、发光边框、渐变文字（P0）
2. emoji 作功能图标（P0）；"Welcome to"/"Lorem ipsum"/空洞占位（P0）
3. 硬编码颜色直出（全部走 Token，design-tokens.json/css 双产出）
4. 卡片彩色左边框、圆角 >16px、同尺寸卡片无限重复网格
5. 每个 section 顶小型大写标签、编号式标题（"01 关于我们"）
6. 橙色白字按钮、橙色大面积背景、蓝橙渐变横幅（logo 除外）
7. 视差/滚动劫持/循环动画、>400ms 动效
8. 虚构指标（"9999+ 客户信赖"）——数字必须来自用户提供的真实经营数据
9. CMS 中出现技术黑话与裸图标按钮
10. 混用第二套图标库/第二种图片摄影风格
