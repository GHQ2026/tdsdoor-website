# ADR-006: 使用腾讯位置服务 GL JS 作为联系页地图

## Status: Accepted (2026-08-28)

## Background

联系我们页需展示公司位置（安徽合肥）。地图选型必须符合中国地图合规要求：仅允许腾讯位置服务、高德、百度地图、天地图；Google Maps、Mapbox、OpenStreetMap/Leaflet 海外瓦片等一律禁止。

## Decision

选用腾讯位置服务 GL JS（Web 端 JS API v1.exp），用户自行在 lbs.qq.com 申请 key 并配置域名白名单，坐标使用 GCJ-02。

理由：
- 合规白名单内，具备审图号。
- 站点托管在腾讯 EdgeOne、生态同源，账号与域名体系统一，交付链路最短。
- Web 端 JS API 对展示型单点场景有充足免费配额；支持 Referer 域名白名单防 key 盗刷。
- 对比高德/百度：功能与配额同级，选择腾讯仅因生态协同；若用户已有高德/百度 key 可等价替换（均为合规白名单方案），代码层将地图封装为独立组件以保留可替换性。

## Consequences

- 正面：合规零风险；与托管栈统一；展示场景零成本。
- 负面：key 申请与白名单配置是用户侧一次性操作（已写入交付步骤）；前端 key 存在被刷量理论风险（展示型场景调用量极小 + 白名单缓解）。
- 硬约束：代码中不得内置任何真实 key（含他人 key），构建/部署时注入；地图 SDK 懒加载（进入视口才加载）以保性能分；容器必须显式固定高度。
