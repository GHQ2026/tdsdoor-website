## 09-03 09:30 修复后台预览：中文LOGO全部破图
- 现象：用户截图，首页客户LOGO墙所有中文文件名LOGO破图（LEXY莱克/五粮液/格力/比亚迪等），仅4个英文名（evps/tcl/jee/cowain）正常
- 诊断：文件全在（19 PNG）、HTML引用全对 → 排除丢文件；破图与"是否含中文"完全相关 → **URL 编码问题**
- 根因1（主因）：浏览器请求中文路径时自动编码成 %XX（如 lexy%E8%8E%B1%E5%85%8B.png），admin/server.py 静态预览直接拿编码后的 path 去文件系统找 → 全部404。修复：do_GET 加 `unquote(self.path)`
- 根因2（附带发现）：服务是单线程 HTTPServer，浏览器挂着空连接时整个服务假死（测试时 timeout/连接拒绝交替出现）。修复：改 **ThreadingHTTPServer** + Handler 加 `timeout = 60`
- 验证：中文LOGO 8/8 全部 200（lexy莱克 75KB / 五粮液 / 格力 / 极狐 / 拓达昇 / 比亚迪 / 安徽建工 / 潮宏基），英文对照正常
- 教训：① Python http.server 处理中文文件名 URL **必须 unquote**；② 本地预览服务必须用 ThreadingHTTPServer，单线程版会被浏览器空闲连接拖死；③ "破图与文件名语言相关"是 URL 编码问题的强特征，先查编码再查文件
- 注意：网站文件本身没问题（线上 CloudStudio 部署一直正常），此 bug 仅影响后台预览通道（localhost:5000/site/...）
